PREDEFINED ELECTRIC VEHICLE TYPES
=================================

The vehicle models listed below correspond to the predefined SUMO
vehicle types available in the vehicle_types.add.xml files used by
EVGen, including:

    sumo_files/custom/vehicle_types.add.xml
    sumo_files_validation/custom/vehicle_types.add.xml

These provided vehicle types can be used when generating synthetic 
trajectories.

Available vehicle models:

- 2013 Nissan Leaf SV                                        -> leaf_2013
- Tesla Model Y Premium RWD (Juniper, LG 5L)                 -> tesla_model_y
- Tesla Model 3 RWD                                          -> tesla_model_3
- Chevrolet Equinox EV 2025 LT FWD                           -> chevrolet_equinox_ev
- Ford Mustang Mach-E 2025 Select RWD Standard Range         -> ford_mustang_mach_e
- Hyundai IONIQ 5 Standard 2WD / 63 kWh RWD                  -> hyundai_ioniq_5
